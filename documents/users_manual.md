# PRMSU Faculty Teaching Load Management System User Manual

## I. Introduction

This user manual explains how to use the PRMSU Faculty Teaching Load Management System (FTLMS).

The system is used to manage faculty teaching loads, prepare class schedules, submit campus-college loads, review submissions, and produce teaching load and schedule documents. It is designed for university personnel, so the instructions focus on what users need to do on each screen.

Use this manual when you need to:

- View your teaching load and class schedule
- Update your personal information or account security
- Create sections and add their courses
- Assign instructors, rooms, and class meeting times
- Submit or revise a campus-college load
- Approve or return a load for correction
- Download or print teaching load and schedule documents
- Manage user accounts and academic records

## II. System Overview and Purpose

FTLMS is a web-based platform for organizing faculty teaching assignments and evaluating campus-college loads for an academic term.

The system connects academic records, sections, course assignments, faculty, rooms, and schedules. A Program Chairperson submits the campus-college load after preparing the records. The system saves a fixed copy, called a **revision** or **snapshot**, for the evaluators to review.

The system helps users by:

- Keeping academic and faculty records in one place
- Showing teaching assignments and remaining scheduling hours
- Checking for conflicting section, faculty, and room schedules
- Recording load submissions, evaluation decisions, and return comments
- Keeping earlier revisions available for reference
- Producing faculty teaching load and class schedule documents
- Controlling available pages and actions through account roles and designations

The main user roles are:

| Role | Main responsibilities |
| --- | --- |
| **Faculty** | Views personal teaching assignments, load information, and schedules; updates personal and account information |
| **Program Chairperson** | Prepares sections and schedules, submits campus-college loads, and corrects returned loads |
| **College Dean** | Monitors college information and works with sections and schedules |
| **Campus Director** | Reviews and approves or returns campus-college loads for the assigned campus |
| **Director for Instruction** | Reviews loads after Campus Director approval |
| **Vice President for Academic Affairs (VPAA)** | Performs the final load review and approval |
| **Admin** | Manages accounts, designations, campuses, colleges, courses, academic ranks, and the academic calendar |

A user may hold more than one designation. Available pages and actions depend on those assignments and their campus, college, or program offering.

The normal load workflow is:

1. The Program Chairperson prepares sections, course assignments, and schedules.
2. The Program Chairperson submits a load revision.
3. The Campus Director reviews the revision.
4. The Director for Instruction reviews the revision.
5. The VPAA completes the final review.

An evaluator can return a load to the Program Chairperson for correction. Resubmission creates a new revision and starts the review again with the Campus Director.

## III. System Requirements

### Minimum and Recommended Hardware Requirements

The system runs in a web browser. Users do not need to install the application on their device.

The following are practical device requirements for using the interface, rather than measured performance specifications.

| Requirement | Minimum | Recommended |
| --- | --- | --- |
| Device | A device that can run a modern web browser | Desktop or laptop for scheduling and administrative work |
| Processor and memory | Enough capacity to run the browser and open PDF documents | A computer that can comfortably run several browser tabs |
| Storage | Enough space for downloaded documents | Additional space for saved PDF reports and supporting files |
| Internet | A working internet connection | Stable internet during saving, uploading, and document export |
| Display | A screen that can show the selected page | A wide desktop display for tables and scheduling |
| Scheduler display | Browser viewport at least 1024 pixels wide | A maximized desktop browser window |

The **Scheduler** requires a larger display. If **Small Screen** appears, maximize the browser window or use a desktop or laptop with a wider screen.

### Software Requirements

Users need:

- A modern web browser, such as Google Chrome or Microsoft Edge
- Internet access
- A valid FTLMS account
- Access to the account's email address for password recovery and email confirmation
- A PDF viewer or a browser that can open PDF files

Allow the system to open new browser tabs when downloading or printing reports.

File upload limits depend on the upload area:

| Upload area | Allowed files | Maximum size per file |
| --- | --- | --- |
| Evaluation return attachments | Any file type | 50 MB as displayed by the system (50 MiB) |
| College logo | PNG, JPG, JPEG, GIF, WEBP, SVG | 5 MB as displayed by the system (5 MiB) |

Load submission uses the records already entered in the system. The Program Chairperson does not need to upload a teaching load document to create a revision.

## IV. Login and Account

   ### Login

   Use the login page to access your account.

   Steps:

   1. Open the FTLMS website provided by your institution.
   2. Enter your **Email**.
   3. Enter your **Password**.
   4. Click **Login**.

   After a successful login, the system opens **Home**. If your account requires email confirmation, follow the confirmation instructions sent to your email before continuing.

   [A screenshot of the Login form that shows Email, Password, Forgot your password?, and Login.]

   ### Getting an Account

   Ordinary user accounts are created by the FTLMS administrator. Contact the administrator if you need an account or if your campus, college, or designation is incorrect.

   During the system's first setup, the first administrator is directed to the administrator account creation page. That administrator must create the account and confirm the email address. This setup page is available only before an administrator account exists.

   Additional administrator accounts can be created through **Users** by an existing administrator.

   ### Forgot Your Password

   To reset your password:

   1. Open the login page.
   2. Click **Forgot your password?**
   3. Enter your account's email address.
   4. Click **Send reset email**.
   5. Open the password reset email and follow its link.
   6. Enter **New password** and **Repeat Password**.
   7. Click **Save new password**.

   If the email does not arrive, check the spam or junk folder and confirm that you entered the correct account email.

   [A screenshot of Reset Your Password that shows the Email field and Send reset email button.]

   ### Me: Overview and Profile

   Click **Me** in the navigation menu. The page has four tabs:

   - **Overview** - account summary, working load, designations, and assigned classes
   - **Profile** - personal, professional, and education information
   - **Schedule** - teaching load and schedule for a selected academic term
   - **Security** - account information, password changes, and email changes

   To update your personal information:

   1. Open **Me**.
   2. Select **Profile**.
   3. Find **Personal Information**.
   4. Update the needed fields, such as your name, professional extension, birth date, contact number, or address.
   5. Click **Save Changes**.
   6. Check for the success message.

   **First Name** and **Last Name** are required. Use **Reset** to discard unsaved changes in that form.

   To update your education information:

   1. Open **Me** > **Profile**.
   2. Find **Education**.
   3. Click **Add Degree**.
   4. Choose the **Level** and enter the degree **Title**.
   5. Add other degrees if needed.
   6. Click **Save Changes**.

   Use **Remove** on a degree to take it out of the list, then save the changes. Every degree left in the list needs a level and title.

   **Professional Information**, including academic rank, employment status, campus, college, and designations, is managed by the administrator. Contact the administrator to request corrections.

   [A screenshot of Me > Overview that shows working load metrics, designations, and Currently Assigned Classes.]

   [A screenshot of Me > Profile that shows Personal Information, Professional Information, Education, and Save Changes.]

   ### Change Your Password

   1. Open **Me** > **Security**.
   2. Find **Update Password**.
   3. Enter your **New Password**.
   4. Enter the same password in **Confirm Password**.
   5. Click **Update Password**.

   The Security form requires at least 8 characters and matching passwords. Use a password that is difficult to guess.

   ### Change Your Email Address

   1. Open **Me** > **Security**.
   2. Find **Change Email Address**.
   3. Enter your new email address and confirm it in the second field.
   4. Click **Change Email**.
   5. Check both your current and new email inboxes.
   6. Follow the confirmation links in both emails to complete the change.
   7. Check the email change status shown on the Security page.

   Keep access to your current email address until the change is complete. Contact the administrator if you cannot access it.

   [A screenshot of Me > Security that shows Security Information, Update Password, and Change Email Address.]

   ### Logout

   1. Save your work.
   2. Click **Logout** in the navigation menu.
   3. In **Confirm Logout**, click **Confirm**.

   Unsaved changes are lost when you log out. Click **Cancel** if you need to return and save them first.

Sections, schedules, and load submissions belong to an academic term.

## VI. Faculty

### Home and Working Load

Faculty can use **Home** and **Me** > **Overview** to check assigned classes and working load information.

The system uses these common terms:

| Term | Meaning |
| --- | --- |
| **ATL** | Actual Teaching Load from teaching assignments |
| **ETL** | Equivalent Teaching Load associated with designations |
| **TWL** | Total Working Load |
| **Revision / Snapshot** | A saved copy of load and schedule information created when a load is submitted |

The personal overview shows **Total Working Load**, **Designation (ETL)**, and **Actual Teaching Load (ATL)**. Review the class and designation details if a value appears incorrect, then contact the Program Chairperson or administrator responsible for the record.

The **Faculty Teaching Load Status** can show:

- **Draft**
- **For Approval by Campus Director**
- **For Approval by DI**
- **For Approval by VPAA**
- **Returned for Revision**
- **Approved**

A class appearing in your account does not by itself mean the campus-college load has completed approval.

### View Your Teaching Load and Schedule

1. Click **Me**.
2. Select **Schedule**.
3. Choose the academic term.
4. Review **Teaching Load**.
5. Review **Schedule** for the day, time, course, room, and section information.

The Teaching Load table shows **Course**, **Lec**, **Lab**, and **Total**. The Schedule table shows meeting times, days, course code and title, lecture or laboratory rooms, and section codes.

The page uses your information from the latest submitted load revision when a matching snapshot is available. If none is available, it uses live class assignments. A recently edited schedule may therefore differ from the saved revision until the Program Chairperson submits a new revision.

[A screenshot of Me > Schedule that shows the academic term selector, Teaching Load, Schedule, and Export.]

### Download or Print Your Teaching Load

1. Open **Me** > **Schedule**.
2. Select the correct academic term.
3. Click **Export** in Teaching Load.
4. Choose **Export as PDF** to open the PDF, or **Print** to open the printable document.
5. Save the PDF or complete the browser's print dialog.

Export is available when a teaching load document exists in a submitted revision snapshot. If Export is disabled, ask the Program Chairperson to check whether your load has been included in a submitted revision.

An available PDF does not by itself indicate final approval. Check the load status separately.

### Report an Incorrect Assignment

If a course, instructor assignment, room, or meeting time is incorrect:

1. Check that you selected the correct term.
2. Record the course, section, day, time, and incorrect detail.
3. Contact the Program Chairperson or College Dean responsible for scheduling.
4. If the issue concerns your campus, college, rank, employment status, or designation, contact the administrator.

Faculty view their assignments through their personal pages. Scheduling changes are handled through the authorized Sections and Scheduler pages.

## VII. Academic Roles

This section covers Program Chairpersons, College Deans, and the three load evaluation roles.

### Program Chairperson and College Dean: Sections

Use **Sections** to create student sections and prepare their course lists.

To create a section:

1. Click **Sections** in the navigation menu.
2. Select the academic term.
3. Click **Create Section**.
4. Choose **Campus**.
5. Choose **Program Offering**.
6. Choose **Major Offering**.
7. Enter **Year Level** and **Name**.
8. Choose **Classification**: **Regular** or **Irregular**.
9. Enter **Student Count** and choose **Advisory Class Faculty**, if needed.
10. Click **Create Section**.

The term follows the page's selected academic term. Section names are converted to uppercase. Year Level must be greater than zero, and Student Count cannot be negative.

The administrator must create the campus's program and major offerings before they can be selected here.

To find or update a section:

1. Use **Search sections**, **Campus**, or **Program** to narrow the list.
2. Select the section.
3. Change the needed fields.
4. Click **Save Changes**.

**Delete Section** opens a confirmation dialog and removes the section and its related class links. Review the selected section and its existing assignments before confirming.

### Add Courses to a Section

1. Open **Sections** and select an existing section.
2. Find **Course Utilization**.
3. Click **Add Course**.
4. Search for and select one or more courses.
5. Click **Add Course** or **Add Courses**, depending on the selection.

The course table shows the course, instructor, lecture and laboratory requirements, units, and merged classes. Courses already added to the section are excluded from the picker.

Important indicators:

- **Unassigned** means a faculty member has not been assigned to the class.
- **Lecture** and **Laboratory** show unscheduled hours compared with total required hours.
- **Total Units** summarizes the section's course units.

Use the three-dot menu beside a course to select **Manage Schedule**. This opens Scheduler with the section and course selected.

To remove a course, use **Remove Course** in the same menu. If the class has scheduled sessions, remove those sessions first; course removal is disabled while sessions remain.

[A screenshot of Course Utilization that shows course rows, Unassigned, remaining hours, Add Course, and the Manage Schedule / Remove Course menu.]

### Create a Class Schedule

The Scheduler shows three grids: **Section**, **Faculty**, and **Room**. Use them together to find a suitable meeting time.

To schedule a class:

1. Open **Scheduler** on a desktop or laptop with a wide browser window.
2. Select the academic term.
3. Under **Section**, click **Select Section** and choose a section.
4. Click **Pick Course** and choose the course offering.
5. Under **Faculty**, click **Select Faculty** and choose the instructor. An existing instructor may already be selected.
6. Under **Room**, choose a room, or choose **Online / No Room**.
7. In the right pane, set **Session Type** to **Lecture** or **Laboratory**.
8. On the Section or Faculty grid, click and drag across consecutive empty cells within one day.
9. Release the mouse to open **Confirm Schedule**.
10. Review the day, start and end times, duration, section, course, faculty, room, and session type.
11. Click **Confirm**.
12. Repeat as needed until the required lecture and laboratory hours are scheduled.

The grid uses 30-minute cells from 7:00 AM to 10:00 PM, Monday through Sunday.

Scheduling checks include:

- A section cannot have overlapping sessions.
- A faculty member cannot teach overlapping sessions.
- A physical room cannot be assigned to overlapping sessions.
- Merged sections must also be available at the selected time.
- A session cannot exceed the course's remaining hours for the selected session type.

Use **Online / No Room** for a session that does not use a physical room. If the class already has a different instructor, use **Replace Faculty** to change that assignment.

[A screenshot of Confirm Schedule that shows the selected class, instructor, room, day, times, and Confirm button.]

### Change or Delete a Scheduled Session

Click an existing class block on a grid. The right pane shows **Selected Class**, its instructor, and its sessions.

To move a session:

1. Click the session's **Edit timeslot** clock icon.
2. Click and drag across the new consecutive time cells on the grid, then release the mouse.
3. Review **Confirm Move**.
4. Click **Move**.

To change a room:

1. Click the pencil beside the session's room.
2. In **Change Room**, select the replacement room or **Online / No Room**.

To replace the instructor:

1. Click the pencil beside **Instructor**.
2. In **Replace Faculty**, select the replacement faculty member.
3. Check the updated instructor and sessions.

Replacing the instructor affects all sessions in that class. A replacement with conflicting commitments is rejected.

To delete a session, click its **Delete session** trash icon. This action removes the session immediately, so check the selected session before clicking. If it was the class's final session, the faculty assignment is also removed; the course remains available for scheduling.

Changes to scheduling records can return submitted or approved loads for revision. Check Campus College Load after making corrections.

[A screenshot of Selected Class that shows the instructor, session list, Edit timeslot, Change Room, Replace Faculty, and Delete session controls.]

### Merge or Unmerge Classes

Merging lets sections taking the same course share a class, instructor, and schedule.

To merge sections:

1. Open **Pick Course** in Scheduler.
2. In **Select Course Offering**, click **Merge with other class** for the course.
3. In **Merge Sections**, select the candidate sections.
4. Review the faculty and combined student count.
5. Choose the intended action:
   - **Join to Them** moves the current section into the selected existing class.
   - **Get Them Join** moves the selected sections into the current class.
6. Review the resulting class membership, instructor, and schedule.

Candidates must be for the same course, campus, and academic term. **Join to Them** requires the selected candidates to belong to one target class. The target class supplies the resulting instructor and schedule. A source class left empty is removed along with its sessions.

A combined student count over 50 displays an advisory indicator. Review the intended class size and available room capacity before proceeding.

To unmerge sections:

1. Open **Select Course Offering**.
2. Click **Unmerge from other class**.
3. In **Unmerge Section**, choose **Detach This Section** or **Detach Other**.
4. For **Detach Other**, select the sections and choose **Single new class for all selected** or **New class per section**.
5. Click **Confirm**.
6. Assign faculty and schedule the detached classes.

Detached classes do not copy the original class's instructor or sessions.

### Program Chairperson: Submit a Campus-College Load

The submission covers a campus and college for one academic term. Prepare the live records in Sections and Scheduler before submitting.

To submit:

1. Open **Campus College Load**.
2. Select the academic term.
3. If you hold both chair and evaluator assignments, select **Program Chair view**.
4. Check the campus-college heading. If you have several assignments, click it to open **Select Campus-College Load**, use **Search scope**, and choose the correct campus and college.
5. Check that the intended sections, courses, faculty, rooms, and meeting times have been entered.
6. Click **Submit Load**.
7. Check the success message, revision number, and status.

The system creates a frozen revision from the current records and sends it to the Campus Director. A submission is available only for a draft or returned load within your chairperson assignment.

Review completeness before clicking Submit Load. Submission creates the review record; it does not replace checking for missing instructors, unscheduled hours, or incorrect section details.

[A screenshot of Program Chair view that shows the campus-college heading, academic term, and Submit Load.]

### Program Chairperson: Correct and Resubmit a Returned Load

1. Open **Campus College Load** and select the correct term and campus-college.
2. Read **Approval Status** and the return reason.
3. Open any reviewer attachments.
4. Use **Sections** and **Scheduler** to make the required corrections.
5. Return to **Campus College Load**.
6. Click **Resubmit Revision**.
7. Check that a new revision was created and the review is with the Campus Director.

If the load says **Automatically Invalidated**, check the recorded reason and the changed source records before resubmitting. A source change can automatically return a load even after final approval.

Resubmitting creates a new snapshot. Earlier revisions and their decisions remain in History, and the new revision must pass all three evaluation steps again.

[A screenshot of a returned load that shows the return comment, supporting attachments, and Resubmit Revision.]

### Campus Director, Director for Instruction, and VPAA: Review Loads

These roles evaluate the same revision in sequence:

| Evaluator | Scope and review position |
| --- | --- |
| Campus Director | First evaluator for the designated campus |
| Director for Instruction | Second evaluator, after Campus Director approval |
| VPAA | Final evaluator, after Director for Instruction approval |

To open a submission:

1. Click **Campus College Load**.
2. Select the academic term.
3. If available, select **Evaluator view**.
4. Select **Pending**.
5. Use **Search campus-college loads** if needed.
6. Select a load.
7. Check the latest revision, **Faculty Load**, **Class Schedule**, and **Approval Status**.
8. Open section details or export documents when needed for review.

The list has **Pending**, **Approved**, and **Returned** filters. **Approved** can mean that your evaluation step is complete while a later evaluator still needs to act. Check the overall load status to confirm final approval.

[A screenshot of Evaluator view that shows Pending, Approved, Returned, the search box, and a selected load.]

### Approve a Load

1. Open a pending load at your evaluation step.
2. Review the latest revision.
3. Click **Evaluate**.
4. Choose **Approve**.
5. Read the confirmation message.
6. Click **Approve** to confirm.

Campus Director approval sends the revision to the Director for Instruction. Director for Instruction approval sends it to the VPAA. VPAA approval marks the load **APPROVED** and its workflow **Completed**.

### Return a Load for Revision

1. Open the pending load and review the latest revision.
2. Click **Evaluate**.
3. Choose **Return / Disapprove**.
4. Enter a clear explanation in **Explain what needs to change**.
5. Add files under **Attachments (optional)** if needed.
6. Wait for all attachments to finish uploading.
7. Click **Return / Disapprove** to confirm.

A return comment is required. Multiple attachments are allowed, with a maximum of 50 MB as displayed by the system (50 MiB) per file.

The load returns to the Program Chairperson. It becomes available for evaluation again after the chairperson submits a new revision.

The Evaluate action appears only when your role can act on the latest submitted revision at its current step.

## VIII. Admin

The Admin role manages the records used by faculty, schedulers, and evaluators.

### Home

Admin Home shows account totals, email confirmation information, recent sign-ins, and user distribution summaries. Use the navigation menu to open the management tools.

[A screenshot of Admin Home that shows Total Users, Confirmed Emails, Active This Week, and Active This Month.]

### Recommended Setup Order

For a new installation, prepare the records in this order:

1. Create colleges, programs, and majors.
2. Create campuses and rooms.
3. Add program offerings and major offerings to campuses.
4. Create courses and academic ranks.
5. Create the academic calendar and set the default term.
6. Create user accounts and assign the correct affiliations and designations.
7. Have the authorized academic users prepare sections and schedules.

This order helps make the required choices available in later forms.

### Users Management

To create an account:

1. Open **Users**.
2. Click **Create User**.
3. Enter **Email** and **Password**.
4. Enter **First Name**, **Last Name**, and **Birth Date**.
5. Choose **Campus**, then **College**.
6. Enter other personal details and employment status as needed.
7. Select **Create as Admin Account** only when creating an administrator.
8. Click **Create User**.

The creation form requires a password of at least 6 characters. The password update forms in **Me > Security** and **Users** require at least 8 characters; use a strong password when creating an account as well.

Employment choices include **Regular**, **Part Time**, **Contract of Service**, and **Temporary**. Available colleges depend on the selected campus's program offerings. If a college is missing, configure its program offering first.

Ordinary user accounts are created with confirmed email. Administrator accounts require email confirmation.

To update an account:

1. Open **Users**.
2. Search for the user or filter by role, campus, or college.
3. Select the user.
4. Update **Personal Information** or **Professional Information**.
5. Click **Save Changes** in the relevant form.

Professional Information includes academic rank, employment status, campus, and college.

Use **Security Settings** to change a user's email address or password. Administrator changes apply directly without sending email verification links. Check the selected user and new email carefully before saving.

**Delete User** in **Danger Zone** permanently deletes the account and associated profile data after confirmation. The currently signed-in administrator cannot delete their own account.

### Assign Designations

Designations control leadership responsibilities, access, and designation load.

1. Open **Users** and select the user.
2. Find **Designations**.
3. Click **Add Designation**.
4. Choose the designation.
5. Supply the required campus, college, or program offering.
6. Enter **Load (hours)** using a nonnegative value.
7. Click **Add Designation**.

Required assignment details:

| Designation | Required context |
| --- | --- |
| College Dean | College |
| Campus Director | Campus |
| Program Chairperson | Program Offering |
| Director for Instruction | No additional context selection |
| Vice President for Academic Affairs | No additional context selection |
| Quality Assurance | No additional context selection |
| Other | A designation title and at least one campus, college, or program offering |

For a Program Chairperson, the selected program offering determines the campus and college used for load submission access. Assign the intended offering carefully.

Additional designation titles may contribute to professional and load records without adding a separate workflow page.

To remove a designation, click the **X** on its card. Removal takes effect immediately. To correct an assignment's scope or load, remove the incorrect designation and add the corrected assignment.

### Campuses, Rooms, and Offerings

To create a campus:

1. Open **Campuses**.
2. Click **Create Campus**.
3. Enter **Campus Code** and **Campus Name**.
4. Enter **Address**, if needed.
5. Click **Create Campus**.

To add a room:

1. Select the campus.
2. Find **Rooms** and click **Add Room**.
3. Enter **Room Code**.
4. Enter **Room Name** and **Capacity**, if needed.
5. Click **Save**.

2. Find **Program Offerings** and click **Add Program Offering**.
3. Select one or more existing programs.
4. Click **Add Programs**.
5. Open the saved program offering.

### Updating and Deleting Reference Records

Management pages provide search, a record list, and a details panel. Use **Save Changes** to save edits and **Reset** to discard unsaved form changes where available.

## IX. The FTLMS Load Process and Documents

### Preparation and Draft

Responsible roles: **Program Chairperson**, with scheduling work also available to **College Dean**.

Status: **DRAFT**, or no submitted revision yet.

Prepare and check:

- Correct academic term, campus, and college
- Sections and their program and major offerings
- Year levels, classifications, and student counts
- Course lists and required lecture and laboratory hours
- Faculty assignments
- Meeting times and rooms
- Merged class membership, when used

The Program Chairperson clicks **Submit Load** to create the first revision and begin evaluation.

### Campus Director Review

Responsible role: **Campus Director**.

Status: **SUBMITTED**, at the Campus Director step.

The Campus Director checks the submitted revision for the designated campus and chooses **Approve** or **Return / Disapprove**.

- Approval sends the revision to the Director for Instruction.
- Return sends the load to the Program Chairperson with a required comment.

### Director for Instruction Review

Responsible role: **Director for Instruction**.

Status: **SUBMITTED**, at the Director for Instruction step.

The Director for Instruction reviews the revision after Campus Director approval.

- Approval sends the revision to the VPAA.
- Return sends the load to the Program Chairperson for a new revision.

### VPAA Review and Final Approval

Responsible role: **Vice President for Academic Affairs**.

Status before the decision: **SUBMITTED**, at the VPAA step.

- **Approve** marks the load **APPROVED** and its current step **Completed**.
- **Return / Disapprove** sends the load back to the Program Chairperson.

An approval by an earlier evaluator is a completed step, while VPAA approval completes the full workflow.

### Returned Loads and Automatic Invalidation

Status: **RETURNED**.

A load can be returned in two ways:

- An evaluator returns it with feedback.
- The system automatically returns it because source records changed after submission or approval.

For an automatic return, the page can show **Automatically Invalidated**, and History records **Automatic Return**.

Changes involving sections, courses, class assignments, and scheduled sessions can trigger an automatic return. This also applies to a fully approved load. The saved revision remains available, but a new submission is needed to review the updated records.

The Program Chairperson checks the feedback or recorded change, corrects the source records, and clicks **Resubmit Revision**. The new revision starts again with the Campus Director.

### Revisions and History

Each submission saves the records as they existed at that time. Later schedule edits do not rewrite an earlier snapshot.

When more than one revision exists, the revision selector lets you open earlier snapshots.

To view another revision:

1. Open the campus-college load.
2. Click the **Revision** selector.
3. In **Select Revision**, choose the revision you need.
4. Check the revision number and **Latest** indicator.

To review prior actions:

1. Open the load.
2. Click **History**.
3. In **Load History**, review **Revision History** for the list of submitted revisions.
4. Review **Ladder History** for the selected revision's decisions, comments, and attachments.
5. To inspect an earlier revision's decisions, close History, select that revision, and open History again.

An older revision may show that it was superseded. Select the latest revision when reviewing the current submission or producing current reports.

### Faculty Load and Class Schedule

The revision detail contains two related views:

| View | What it covers |
| --- | --- |
| **Faculty Load** | Faculty whose home campus and college match the load; includes their teaching assignments for the term, including classes in other colleges |
| **Class Schedule** | Sections belonging to the selected campus and college, including classes taught by instructors from other home colleges |

These different scopes can explain differences between faculty totals and section totals.

Faculty Load groups faculty by employment status and shows designation, ETL, lecture hours, laboratory hours, preparations, equivalent units, ATL, and TWL.

Class Schedule groups sections by year level. Expand a year level and select a section to inspect its courses, instructors, days, times, and rooms.

Common indicators include:

- **Unassigned** - no instructor assigned
- **TBA** - a schedule detail has not been set
- **Overloaded** - the section's total lecture and laboratory units exceed 21

Review these indicators before approving or distributing documents.

## X. Frequently Asked Questions

### Why is a page missing from my navigation menu?

Pages depend on your roles and designations. Ask the administrator to check your assignment and its campus, college, or program offering.

### Can a College Dean approve a campus-college load?

The load evaluation steps belong to the Campus Director, Director for Instruction, and VPAA. A College Dean can work with Sections and Scheduler. A user with an additional evaluation designation can act through that role when its step is available.

### Why does my Home page look different from another user's Home page?

Home depends on your role and assignment scope. An account with several roles normally displays the dashboard for the highest assigned role.

### What is the difference between live records and a revision?

Live records are the current sections, classes, and schedules. A revision is a saved copy created during load submission. Editing live records does not change that saved copy.

### Why does Me > Schedule show older information than Scheduler?

Me > Schedule uses the latest matching submitted snapshot when one is available. The Program Chairperson needs to submit a new revision for the updated records to appear in that snapshot view.

### Why did an approved load return for revision?

A change to source data can automatically invalidate a submitted or approved load. Check the recorded reason, review the changes, and have the Program Chairperson resubmit the load.

### Does resubmission keep earlier approvals?

Earlier decisions remain in the earlier revision's history. The new revision starts again with the Campus Director and needs all three evaluation steps.

### Does the evaluator's Approved filter mean the whole load is fully approved?

It can mean that the evaluator's own step is complete. Check the overall status and Approval Status. Full approval occurs after the VPAA approves the revision.

### Does an available PDF mean my load is approved?

No. Documents can be available from submitted snapshots before final approval. Check the load status separately.

### Why do faculty totals differ from the class schedule totals?

Faculty Load follows faculty home campus and college and includes their assignments elsewhere. Class Schedule follows section ownership in the selected campus and college. They cover different sets of records.

### What do Unassigned, TBA, and Overloaded mean?

Unassigned means an instructor has not been set. TBA means a schedule detail has not been entered. Overloaded marks a section whose total lecture and laboratory units exceed 21.

### Can I upload a teaching load file instead of preparing records?

Load submission creates the snapshot from system records. Prepare the sections, courses, faculty assignments, and schedules before submitting.

### Why can I not remove a section course?

A course with scheduled sessions cannot be removed through Course Utilization. Remove its sessions first, then remove the course.

## XI. Troubleshooting

### I Cannot Log In

Try the following:

1. Check your email address and password.
2. Complete email confirmation if it is required for your account.
3. Use **Forgot your password?** if needed.
4. Contact the administrator to check that your account exists and uses the correct email address.

### I Did Not Receive a Password Reset or Confirmation Email

1. Check the spam or junk folder.
2. Confirm that you used the account's correct email address.
3. Wait a few minutes before requesting another password reset.
4. For an email change, check both the current and new inboxes.
5. Contact the administrator if the issue continues.

### The Scheduler Shows Small Screen

1. Maximize the browser window.
2. Use a wider screen or a desktop or laptop.
3. Ensure the browser viewport is at least 1024 pixels wide.

### No Academic Term or Dashboard Information Appears

Ask the administrator to check that the academic calendar exists and the correct term is set as Default. On pages with a term selector, select the intended term directly.

### A Campus, Program, Major, Room, or Faculty Member Is Missing

1. Check the selected term and any search or filter settings.
2. Check that the selected campus has the required program and major offerings.
3. Ask the administrator to check the reference record, user affiliation, or designation.

### A Schedule Cannot Be Confirmed or Moved

Check the following:

- The correct section, course, faculty, and room or Online / No Room are selected.
- The selected Session Type has enough remaining hours.
- The selected range fits the 30-minute grid.
- The section and any merged sections are available.
- The faculty member is available.
- The physical room is available.
- An existing instructor assignment has been changed through Replace Faculty when needed.

Choose another valid time, room, or instructor according to the displayed error.

### I Deleted the Wrong Session

Session deletion takes effect immediately. Select the course and recreate the session at the intended time. If it was the final session, select the faculty again before scheduling. Check whether the change also returned a submitted load for revision.

### Submit Load or Resubmit Revision Is Missing

1. Confirm that your account has a Program Chairperson designation for the selected campus-college.
2. Select **Program Chair view** if the role switcher is available.
3. Check the academic term and campus-college selection.
4. Check the status: submission is available for draft or returned loads.
5. Contact the administrator if the assignment is incorrect.

### Evaluate Is Missing

1. Check that you are in Evaluator view, if available.
2. Select the latest revision.
3. Check that the load is submitted and currently at your evaluation step.
4. For Campus Director review, check that the load belongs to your designated campus.
5. Refresh the page if another user may have already acted.

### A Return Attachment Will Not Upload

1. Check that each file is within the 50 MB displayed limit.
2. Check your internet connection.
3. Reattach the file if the system reports that it cannot be found.
4. Wait until uploads finish before confirming the return.

For a college logo, also check the allowed image format and 5 MB displayed limit.

### A PDF or Print Window Does Not Open

1. Allow pop-ups and new tabs for the FTLMS website.
2. Check that the correct term and revision are selected.
3. Wait for the document to finish loading.
4. Try the export again if the system displays a generation error.
5. Contact support if the error continues, including the document type and revision.

### My Faculty Export Button Is Disabled

Check the term and ask the Program Chairperson whether a revision containing your faculty teaching load has been submitted. Live assignments alone may be visible before a snapshot document is available.

### I Cannot Save or Delete an Administrative Record

Read the displayed error. Check required fields, duplicate codes, date ranges, and existing references. Some codes are locked after creation, and some records cannot be deleted while related records exist.

For academic calendar corrections, contact technical support if the needed change has no control on the current page.

### The Page Does Not Update or Shows an Error

1. Save any work that can still be saved.
2. Check your internet connection.
3. Refresh the page.
4. Log out and log in again if needed.
5. Try another modern browser.
6. Contact support if the issue continues.
